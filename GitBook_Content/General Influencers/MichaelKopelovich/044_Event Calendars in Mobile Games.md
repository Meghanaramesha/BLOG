Some games (like SOULS and Capybara Go!) now feature a built-in event calendar that lets players see current and upcoming events directly inside the game.  
  
Why it’s interesting:  
✅ Builds anticipation — players know what’s coming next.  
✅ Reduces churn — fewer surprises = more planned engagement.  
✅ Strengthens event monetization — players can prep resources (and wallets 💳).  
  
Of course, only larger live-ops teams can realistically run and maintain this at scale. But it’s a great reminder of how transparency + planning tools can boost player trust and retention.  
  
👉 Would you add an event calendar to your game, or do you prefer to keep things more spontaneous?
